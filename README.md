# AGENTVERSE

**Your vision. Your AI company. Your universe.**

AGENTVERSE is a futuristic software studio prototype where a team of specialized AI-agent roles coordinates software missions through an interactive 3D office.

> **Prototype honesty:** the current app runs in demo mode. It demonstrates the product interaction and workflow locally; it does not yet call an LLM, execute generated code, or deploy applications. Agent events in demo mode are simulated. No API key is required for the UI prototype.

## Planned prototype features
- Interactive Three.js virtual office with six agent stations
- Role-based agent directory: Commander, Oracle, Pixel, Forge, Sentinel, Critic
- Mission creation, sample task plan, progress, event feed, approvals, and artifacts
- Next.js + TypeScript + React Three Fiber
